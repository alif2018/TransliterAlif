Cara Install Add-in

💻 Kompatibilitas Versi Office:

  • Microsoft 365 (Windows & Mac)
  • Word 2016, 2019, 2021, 2024
  • Word Online (Browser Web)
  • Word untuk Mac & iPad

*Tidak didukung di Office 2013 atau versi lebih lama.

Ikuti panduan manual berikut untuk memasang di Microsoft Word (Desktop):

Langkah 1: Buat dan Bagikan Folder

  1. Buka Windows Explorer, buat folder baru di drive C: (contoh: C:\OfficeAddins).
  2. Pindahkan file XML Anda ke dalam folder tersebut.
  3. Klik kanan folder OfficeAddins > pilih Properties.
  4. Masuk ke tab Sharing, lalu klik tombol Advanced Sharing....
  5. Centang kotak Share this folder.
  6. Klik tombol Permissions, pastikan grup Everyone mendapatkan hak akses Read. Klik OK.
  7. Klik Apply lalu OK.
  8. Kembali ke tab Sharing, lihat di bagian Network Path. Catat alurnya (contoh: \\NAMA-PC\OfficeAddins).

Langkah 2: Daftarkan ke Trust Center

  1. Buka aplikasi Excel atau Word versi Desktop.
  2. Klik menu File > pilih Options.
  3. Pilih menu Trust Center di panel kiri, lalu klik Trust Center Settings....
  4. Pilih menu Trusted Add-in Catalogs.
  5. Pada kolom Catalog Url, tempelkan (paste) Network Path folder tadi (contoh: \\NAMA-PC\OfficeAddins).
  6. Klik tombol Add Catalog.
  7. Centang kotak Show in Menu pada baris katalog yang baru Anda tambahkan.
  8. Klik OK, lalu klik OK lagi untuk menutup jendela Options.
  9. Tutup dan Buka Kembali (Restart) aplikasi Word Anda.

Langkah 3: Jalankan Add-in

  1. Buka kembali dokumen Word baru.
  2. Masuk ke tab Insert di ribbon atas.
  3. Klik tombol My Add-ins (atau Get Add-ins > pilih tab My Add-ins).
  4. Klik tab/opsi SHARED FOLDER di bagian atas jendela yang muncul.
  5. Anda akan melihat nama Add-in yang tertera di file XML Anda.
  6. Klik add-in tersebut, lalu klik tombol Add.
  7. Tombol Add-in Anda akan muncul di ribbon (biasanya di tab Home). Klik tombol tersebut untuk membuka panel transliterasi ini!
